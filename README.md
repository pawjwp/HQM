# Multipurpose Assistance Terminal

## About

**Multipurpose Assistance Terminal** is a fork of [Hardcore Questing Mode](https://www.curseforge.com/minecraft/mc-mods/hardcore-questing-mode) (HQM). The original mod allows modpack authors to make quests and quest lines for their players to follow, and adds an alternate hardcore mode where players can earn more lives. This fork makes various improvements to the existing quest book and the general user experience. It also adds the Multipurpose Assistance Terminal (MAT) itself, which combines the quest book and several other tools into a single item.

The questing-related changes from the original HQM include new keybinds, JEI integration, fixes to completion percentage, automatic backups, new task options, and more. The version 5.x.x releases include only these HQM changes without any MAT-related content.

It also adds the MAT itself, a terminal with 5 modes (Info, Questing, Storage, Crafting, and Tracking), plus the tutorial system, data chips, and more. Every new feature is optional and can be disabled individually. More modes may be added at some point in the future.
